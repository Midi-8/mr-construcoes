# MR Construções — Website Institucional

Site institucional da **MR Construções**, empresa de construção, remodelação e reparações com sede em Vila Nova de Famalicão.

---

## 📋 Sobre o Projeto

Website desenvolvido para apresentar os serviços, portfólio e contactos da MR Construções. Construído com tecnologias web simples e sem dependências externas, garantindo rapidez, leveza e facilidade de manutenção.

---

## 🗂️ Estrutura do Projeto

```
mr-construcoes/
├── index.html        # Estrutura HTML principal
├── style.css         # Estilos e layout (responsivo)
├── script.js         # Lógica e interatividade
├── imagens/          # Fotografias e logótipo
└── README.md         # Este ficheiro
```

---

## ⚙️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica e acessível
- **CSS3** — Layout responsivo com Grid e Flexbox, animações, design mobile-first
- **JavaScript (Vanilla)** — Interatividade sem frameworks ou dependências
- **Google Fonts** — Tipografias Inter e Playfair Display

---

## 📄 Secções do Site

| Secção | Descrição |
|---|---|
| **Hero / Início** | Slideshow com projetos em destaque e controlos de navegação |

## 🚀 Como Correr Localmente

Não é necessária qualquer instalação. Basta abrir o ficheiro diretamente no browser:

```bash
# Opção 1 — abrir diretamente
Abrir index.html no browser

# Opção 2 — servidor local simples (Python)
python -m http.server 8000
# Aceder em: http://localhost:8000
```
