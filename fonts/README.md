# Fontes da Família Orelo

- **Designer:** Adrien Midzic
- **Fundição (Foundry):** Pizza Typefaces
- **Classificação:** Display Sans-Serif de alto contraste (Peignotian / Flared)

O website está totalmente configurado para detetar e utilizar a fonte **Orelo** instalada no sistema operacional ou através de ficheiros web colocados nesta pasta (`fonts/`):

### Nomes de ficheiros suportados:
1. `OreloVariable.woff2` (versão variável completa)
2. `Orelo-Regular.woff2` ou `Orelo-Regular.woff`
3. `Orelo-SemiWide-Regular.woff2` ou `Orelo-SemiWide-Regular.woff`
4. `Orelo-SemiWide-Bold.woff2` ou `Orelo-SemiWide-Bold.woff`
